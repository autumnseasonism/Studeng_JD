# 大学生求职陪跑助手 产品需求说明 v1.0

## 0. 自包含说明

本文档是自包含产品规格。开发 agent 只需要读取 `docs/PRODUCT_SPEC.md`、`docs/AGENT_HANDOFF.md`、`docs/IMPLEMENTATION_CHECKLIST.md` 与 `prompts/` 目录，即可理解和开发第一版产品。

本文档不是可直接运行的应用代码。产品落地仍需实现 Next.js 前端、FastAPI 后端、SQLite 存储、文件解析、DeepSeek API 调用和本地 IndexedDB 历史。

## 1. 产品概述

- 产品名称：大学生求职陪跑助手
- 产品类型：AI 驱动的简历诊断与改写 Web 应用
- 目标用户：
  - 正在找实习的大学生
  - 校招应届生
  - 转专业或跨方向求职的学生
  - 0-1 年早期求职者
- 解决的问题：
  - 用户不知道简历哪里弱。
  - 用户不知道如何根据岗位 JD 调整表达。
  - 用户缺少把课程项目、实习、竞赛、校园经历写成能力证明的方法。
  - 用户希望获得一份可复制、可编辑、可预览的 Markdown 优化简历。
- 核心价值：
  - 把“上传简历 -> 诊断问题 -> 获得修改建议 -> 生成可编辑简历”的过程产品化。
  - 用温和陪跑教练的方式指出问题，避免羞辱式评价。
- 产品形态：
  - Web 应用，桌面端优先，移动端支持查看和复制。
  - 前端不直接调用 DeepSeek，所有 AI 请求由后端代理。

## 2. 页面清单与信息架构

| 页面/模块 | 层级 | 承担任务 | 入口 | 出口 |
|---|---|---|---|---|
| 上传页 | L1 核心入口 | 上传简历、粘贴简历文本、填写可选 JD、查看 IP 额度 | 访问应用首页、本地历史重新分析 | 分析进度页、本地历史 |
| 分析进度页 | L1 过程页 | 展示文件解析和 AI 分析阶段 | 上传页点击开始分析 | 审计报告页、失败重试 |
| 审计报告页 | L1 核心结果页 | 展示整体诊断、评分、风险、模块建议 | 分析完成、本地历史打开 | 改写编辑器、版本对比、追问区 |
| 改写编辑器页 | L1 核心结果页 | 编辑 Markdown 简历并实时预览 | 审计报告页点击查看优化简历 | 导出页、版本对比、本地保存 |
| 版本对比页 | L1 辅助结果页 | 对比原始简历与优化版本，解释修改原因 | 审计报告页、编辑器页 | 返回报告页或编辑器页 |
| 导出页 | L1 辅助结果页 | 复制 Markdown、复制纯文本、下载 `.md` | 编辑器页 | 返回编辑器页 |
| 本地历史面板 | L2 本地数据层 | 查看历史分析、恢复结果、删除历史 | 顶部历史入口 | 打开报告页、清空历史 |
| 后续追问面板 | L2 辅助对话层 | 基于当前分析结果答疑或局部改写 | 报告页或编辑器页右侧 | 保存局部改写、返回当前页 |

### 导航方式

- 主流程：上传页 -> 分析进度页 -> 审计报告页 -> 改写编辑器页 -> 导出页。
- 辅助流程：审计报告页可进入版本对比页和后续追问面板。
- 本地历史可从任意主页面打开，历史结果不消耗新的完整分析额度。

## 3. 页面布局结构

### 3.1 上传页

- 页面头部：
  - 产品名“大学生求职陪跑助手”
  - 今日完整分析剩余额度
  - 本地历史入口
- 内容区：
  - 左侧：文件上传卡片
    - 支持拖拽上传
    - 支持 PDF、DOCX、TXT、MD
    - 显示文件名、文件大小、格式校验结果
  - 右侧：表单区
    - 简历文本粘贴框
    - 目标岗位输入框
    - JD 文本框
    - 求职类型选择：实习、校招、转专业、早期求职
- 操作区：
  - “开始分析”主按钮
  - “清空”按钮
  - “查看示例”入口
- 校验：
  - 文件和简历文本至少提供一个。
  - 单个文件最大 10MB。
  - 单次只允许一份简历。
  - JD 可为空。

### 3.2 分析进度页

- 顶部：任务标题和返回上传页入口。
- 中部：阶段进度条。
  - 解析简历
  - 理解岗位
  - 生成诊断
  - 生成修改建议
  - 生成 Markdown 简历
- 底部：状态提示。
  - 当前阶段说明
  - 已等待时间
  - 失败后的重试或返回入口
- 规则：
  - 不展示复杂流式文本。
  - 分析完成后自动进入审计报告页。

### 3.3 审计报告页

- 页面头部：
  - 简历名称或上传文件名
  - 创建时间
  - 是否基于 JD 分析
  - 返回上传页、本地历史入口
- 顶部摘要区：
  - 整体竞争力评分
  - 竞争力等级
  - 3 个优先修改项
  - 有 JD 时展示岗位匹配度；无 JD 时展示“未提供 JD，仅做通用诊断”
- 模块审计区：
  - 教育背景
  - 实习经历
  - 项目经历
  - 科研/竞赛经历
  - 校园/社团/志愿经历
  - 技能证书
  - 个人总结
- 单条建议卡片字段：
  - 模块名称
  - 原始片段
  - 问题
  - 影响
  - 修改方向
  - 示例改写
  - 待补充信息
  - 优先级
- 右侧操作区：
  - 查看优化简历
  - 查看版本对比
  - 继续追问

### 3.4 改写编辑器页

- 两栏布局：
  - 左侧：Markdown 编辑器
  - 右侧：实时预览
- 顶部工具栏：
  - 当前版本名称
  - 保存本地版本
  - 复制 Markdown
  - 复制纯文本
  - 下载 `.md`
  - 查看对比
- 编辑规则：
  - 用户修改内容后实时更新预览。
  - 保存版本只写入浏览器本地 IndexedDB。
  - 不因为编辑行为消耗后端 AI 额度。

### 3.5 版本对比页

- 左侧：原始简历片段。
- 右侧：优化后片段。
- 下方或右侧说明：
  - 修改原因
  - 对简历表达的影响
  - 仍需补充的信息
- 操作：
  - 返回编辑器
  - 定位到对应建议卡片

### 3.6 导出页

- 预览区：展示最终 Markdown 简历渲染效果。
- 操作区：
  - 复制 Markdown
  - 复制纯文本
  - 下载 `.md`
- 不支持：
  - PDF 导出
  - DOCX 导出
  - 云端同步

### 3.7 本地历史面板

- 展示字段：
  - 分析标题
  - 创建时间
  - 是否包含 JD
  - 求职类型
  - 本地版本数量
- 操作：
  - 打开历史报告
  - 删除单条历史
  - 清空全部历史
- 规则：
  - 历史只存在用户浏览器本地。
  - 清理浏览器数据会导致历史丢失。

## 4. 关键组件与状态

| 组件 | 默认状态 | 加载状态 | 成功状态 | 错误状态 |
|---|---|---|---|---|
| 文件上传卡片 | 等待上传 | 读取文件名和大小 | 展示文件信息 | 格式不支持、超过 10MB |
| JD 输入区 | 空白可填 | 无 | 已填写时标记“将进行岗位匹配” | 不做错误阻断 |
| 额度提示条 | 显示剩余额度 | 查询中 | 展示剩余次数 | 查询失败时提示稍后重试 |
| 开始分析按钮 | 可点击或置灰 | Spinner，禁止重复点击 | 跳转进度页 | 展示失败原因 |
| 阶段进度条 | 未开始 | 当前阶段高亮 | 全部完成 | 失败阶段标红 |
| 建议卡片 | 展示建议 | 无 | 可展开查看示例 | JSON 缺字段时展示兜底文本 |
| Markdown 编辑器 | 显示生成版本 | 无 | 可编辑保存 | 本地保存失败提示 |
| 历史面板 | 展示历史列表 | 读取 IndexedDB | 可打开历史 | 本地读取失败提示 |
| 追问输入框 | 可输入 | 等待 AI 回复 | 追加回复 | 额度用完或 API 失败 |

## 5. 关键交互流程

### 5.1 完整分析流程

1. 用户进入上传页。
2. 前端调用 `GET /api/quota` 查询当前 IP 额度。
3. 用户上传文件或粘贴简历文本。
4. 用户可填写目标岗位和 JD；不填写也允许继续。
5. 用户点击“开始分析”。
6. 前端校验文件大小、数量、格式和文本输入。
7. 后端校验 IP 额度和每分钟提交限制。
8. 后端解析文件，得到 `{text, file_type, warnings}`。
9. 后端调用 DeepSeek 完成 JD 分析、诊断、模块审计、Markdown 改写、版本对比。
10. 前端展示进度状态。
11. 分析完成后进入审计报告页。
12. 前端把完整结果写入 IndexedDB。
13. 后端删除上传文件，仅保留 24 小时临时任务数据。

### 5.2 无 JD 分析流程

1. 用户不填写 JD，点击“开始分析”。
2. 后端跳过岗位匹配或返回 `has_jd=false` 的 JD 分析结果。
3. 诊断报告不展示岗位匹配度。
4. 报告展示通用校招/实习竞争力诊断。

### 5.3 本地历史查看流程

1. 用户点击本地历史入口。
2. 前端从 IndexedDB 读取历史列表。
3. 用户打开某条历史。
4. 前端恢复审计报告、Markdown 简历、版本对比、追问记录。
5. 该行为不调用完整分析接口，不消耗每日完整分析额度。

### 5.4 后续追问流程

1. 用户在报告页或编辑器页打开追问面板。
2. 前端调用后端追问接口。
3. 后端检查当前 IP 每日 20 次追问额度。
4. 后端把当前报告、当前 Markdown、用户问题发送给 DeepSeek。
5. 返回答复或局部改写建议。
6. 前端把追问记录保存到 IndexedDB。

### 5.5 编辑与导出流程

1. 用户进入改写编辑器页。
2. 用户直接编辑 Markdown。
3. 右侧预览实时更新。
4. 用户点击保存版本，前端写入 IndexedDB。
5. 用户点击复制 Markdown 或复制纯文本，内容写入剪贴板。
6. 用户点击下载 `.md`，浏览器下载当前 Markdown 文件。

## 6. 空状态、加载状态、错误状态

### 6.1 空状态

- 上传页无输入：提示“上传简历或粘贴文本后即可开始分析”。
- 本地历史为空：提示“暂无历史分析，完成一次分析后会自动保存在本地”。
- 审计报告无 JD：提示“未提供目标岗位，当前仅展示通用校招/实习诊断”。
- 版本列表为空：提示“保存编辑后会生成本地版本”。
- 追问记录为空：提示“可以询问某条建议为什么这样改，或让助手帮你局部改写”。

### 6.2 加载状态

- 额度查询：顶部额度区域显示 Skeleton。
- 文件解析：进度页高亮“解析简历”。
- AI 分析：进度页依次高亮后续阶段。
- 本地历史读取：历史面板显示列表 Skeleton。
- 追问等待：输入框禁用，按钮显示 Spinner。

### 6.3 错误状态

- 文件超过 10MB：提示“文件超过 10MB，请压缩或改用文本粘贴”。
- 文件格式不支持：提示“当前仅支持 PDF、DOCX、TXT、MD”。
- 文本型 PDF 解析失败：提示“这份 PDF 可能是扫描版或图片型文件，请上传 DOCX/TXT/MD，或直接粘贴简历文本”。
- 今日完整分析额度用完：提示“今日该网络下的完整分析次数已用完，你仍可查看本地历史结果”。
- 追问额度用完：提示“今日追问次数已用完，请明天再试”。
- DeepSeek API 超时：提示“AI 服务响应超时，请稍后重试”。
- 本地历史保存失败：提示“本地保存失败，请检查浏览器存储权限或剩余空间”。

## 8. 关键业务规则

### 8.1 文件规则

- 单次只允许 1 份简历。
- 文件大小上限 10MB。
- 支持 PDF、DOCX、TXT、MD、直接粘贴文本。
- PDF 仅保证支持可复制文字的文本型 PDF。
- 不支持 DOC、图片 OCR、扫描 PDF OCR、多文件合并。

### 8.2 JD 规则

- JD 建议填写但不强制。
- 有 JD 时展示岗位匹配度、关键词覆盖、岗位差距。
- 无 JD 时不展示岗位匹配度，只展示通用校招/实习诊断。

### 8.3 AI 输出规则

- 不编造经历、公司、奖项、成绩、证书、数据。
- 缺失信息使用 `[待补充：...]`。
- 修改建议必须包含问题、影响、修改方向、示例改写。
- 示例改写必须基于原始简历信息。
- 禁止承诺面试、offer 或通过率。

### 8.4 额度规则

- 每个 IP 每天最多 1 次完整简历分析。
- 每个 IP 每天最多 20 次后续追问。
- 每个 IP 每分钟最多 1 次完整分析提交。
- 额度用完后允许查看本地历史、编辑本地版本、复制和下载已有结果。

### 8.5 数据保存规则

- 用户长期历史只保存在浏览器 IndexedDB。
- 后端临时任务数据保留 24 小时。
- 上传文件分析完成后立即删除。
- 异常任务文件 24 小时内清理。

### 8.6 API Key 安全规则

- DeepSeek API Key 只能配置在后端环境变量中，例如 `DEEPSEEK_API_KEY`。
- 前端不得直接调用 DeepSeek API。
- 禁止使用 `NEXT_PUBLIC_*` 保存 DeepSeek API Key。
- 日志、错误响应、调试信息中不得输出 DeepSeek API Key 或完整请求头。
- Git 仓库不得提交真实密钥或真实密钥样例。

## 9. 技术栈与交付要求

- 前端：Next.js。
- 后端：FastAPI。
- AI：DeepSeek API。
- 数据库/频控：SQLite。
- 本地历史：IndexedDB。
- 文件解析：
  - PDF：文本型 PDF 解析，建议使用 `pypdfium2` 或同类库。
  - DOCX：解析段落和表格文本。
  - TXT/MD：直接读取。
- 部署策略：
  - 先交付本地可运行 Demo。
  - 后续整理服务器部署配置。
- 服务器保护：
  - 完整分析并发数先设为 1。
  - Nginx 上传限制 10MB。
  - 日志轮转保留 7-14 天。
  - DeepSeek 请求设置超时、失败重试和错误兜底。

## 10. 非目标范围

- 不支持 PDF 导出。
- 不支持 DOCX 导出。
- 不做支付/会员。
- 不做后台管理端。
- 不做 ATS 投递追踪。
- 不做云端账号系统。
- 不做多设备同步。
- 不承诺 offer、面试或通过率。
