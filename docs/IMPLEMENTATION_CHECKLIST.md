# 实现与验收清单

## 产品目标与用户

- [ ] 明确产品名为「大学生求职陪跑助手」。
- [ ] 首页或首屏说明目标用户是实习、校招、应届生、转专业和早期求职者。
- [ ] 产品核心流程是上传/粘贴简历、可选 JD、生成诊断、生成 Markdown 简历。

## 页面清单和页面关系

- [ ] 上传页存在。
- [ ] 分析进度页存在。
- [ ] 审计报告页存在。
- [ ] 改写编辑器页存在。
- [ ] 版本对比页存在。
- [ ] 导出页存在。
- [ ] 本地历史入口存在。
- [ ] 后续追问入口存在。
- [ ] 主流程符合：上传 -> 进度 -> 报告 -> 编辑 -> 导出。

## 页面布局结构

- [ ] 上传页包含文件上传、文本粘贴、目标岗位、JD、求职类型、额度展示。
- [ ] 进度页包含五个阶段状态。
- [ ] 报告页包含评分、竞争力等级、优先修改项、模块化建议。
- [ ] 编辑器页为 Markdown 编辑和实时预览两栏布局。
- [ ] 对比页展示原文、改写后内容、修改原因。
- [ ] 导出页提供复制 Markdown、复制纯文本、下载 `.md`。

## 关键组件与状态

- [ ] 文件上传卡片覆盖默认、加载、成功、错误状态。
- [ ] 额度提示覆盖查询中、可用、用完、查询失败状态。
- [ ] 开始分析按钮覆盖可点击、置灰、加载、失败状态。
- [ ] 阶段进度条覆盖未开始、处理中、完成、失败状态。
- [ ] 建议卡片可展开查看问题、影响、修改方向、示例改写。
- [ ] Markdown 编辑器支持编辑、预览、保存失败提示。
- [ ] 追问输入框支持额度用完和接口失败状态。

## 关键交互流程

- [ ] 完整分析流程可从上传页走到审计报告页。
- [ ] 无 JD 流程不展示岗位匹配度。
- [ ] 有 JD 流程展示岗位匹配度和关键词覆盖。
- [ ] 本地历史打开不消耗完整分析额度。
- [ ] 后续追问消耗追问额度。
- [ ] 编辑和导出不调用 AI，不消耗额度。

## 空状态、加载状态、错误状态

- [ ] 上传页空输入有引导文案。
- [ ] 本地历史为空有引导文案。
- [ ] 报告无 JD 有明确提示。
- [ ] 额度查询有 Skeleton 或加载态。
- [ ] 文件解析和 AI 分析有阶段加载态。
- [ ] 文件超 10MB 有错误提示。
- [ ] 格式不支持有错误提示。
- [ ] 扫描版 PDF 解析失败有替代建议。
- [ ] DeepSeek 超时有错误提示。
- [ ] IndexedDB 保存失败有错误提示。

## 核心数据对象

- [ ] ExtractedDocument 数据结构存在。
- [ ] QuotaStatus 数据结构存在。
- [ ] AnalysisTask 数据结构存在。
- [ ] AnalysisResult 数据结构存在。
- [ ] LocalHistoryRecord 数据结构存在。
- [ ] ResumeVersion 数据结构存在。
- [ ] FollowupMessage 数据结构存在。

## 关键业务规则

- [ ] 单次只允许 1 份简历。
- [ ] 单文件最大 10MB。
- [ ] 支持 PDF、DOCX、TXT、MD、文本粘贴。
- [ ] 不支持 DOC、OCR、多文件合并。
- [ ] 每 IP 每天 1 次完整分析。
- [ ] 每 IP 每天 20 次追问。
- [ ] 每 IP 每分钟 1 次完整分析提交。
- [ ] 上传文件分析完成后删除。
- [ ] 后端临时任务 24 小时清理。
- [ ] 本地历史保存在 IndexedDB。

## 技术和安全

- [ ] 前端使用 Next.js。
- [ ] 后端使用 FastAPI。
- [ ] 频控和临时任务使用 SQLite。
- [ ] DeepSeek API Key 只在后端环境变量中。
- [ ] 前端不能看到 DeepSeek API Key。
- [ ] Git 中不能出现真实密钥。
- [ ] DeepSeek 请求有超时和失败兜底。

## Prompt 质量

- [ ] 所有大模型提示词集中在 `prompts/`。
- [ ] Prompt 明确输入变量。
- [ ] Prompt 明确输出格式。
- [ ] Prompt 要求缺失信息用 `[待补充：...]`。
- [ ] Prompt 禁止编造经历、公司、奖项、成绩、证书、数据。
- [ ] Prompt 不使用空泛的写作要求。
